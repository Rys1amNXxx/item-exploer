# 物品搜索（0.4.0-dev）

终端可以搜索当前主存储盘或当前 NAS 硬盘内的物品。不会搜索未选中的盘、
其他终端、玩家背包或世界中的物品。搜索状态只存在于当前菜单会话，不改变库存存档格式。

## 打开、范围与退出

点击顶部“搜索”，或按 Ctrl+F。再次按 Ctrl+F 将焦点放回输入框。
顶部目录操作区切换为查询框、范围和退出按钮，原有翻页与背包位置保持不变。

- 默认“全盘”：当前盘的所有目录。
- “目录树”：进入搜索时的当前目录及其所有子目录，锚目录不会随搜索结果选择改变。
- 更改查询或范围回到结果第一页；输入停顿约 200 毫秒后更新，也可按 Enter 提交。
- 清空查询显示范围内所有物品。点击退出按钮或按 Esc 返回原目录及页码；
  若目录已被其他玩家删除，返回根目录。
- 点击左侧目录树或上方路径可退出搜索并进入所选目录；切盘会清理原搜索上下文。

## 匹配规则

| 查询 | 含义 |
| --- | --- |
| `铁` | 名称或自定义名称包含“铁” |
| `iron` | 名称或注册 ID 包含 `iron` |
| `iron ingot` | 同时包含 `iron` 和 `ingot`，例如 `minecraft:iron_ingot` |
| `minecraft:iron_ingot` | 注册 ID 包含这一文本 |
| `@mekanism` | 物品注册 ID 的命名空间包含 `mekanism` |
| `@mekanism 铁` | 同时满足命名空间和名称 / ID 条件 |

查询最长 64 个 UTF-16 代码单元；忽略大小写，空白分隔的词均需匹配。
物品名称按玩家客户端当前语言解析。英文名称不会自动与中文名称互译，
英文查询可通过注册 ID 匹配；自定义名称按其实际文本匹配。
文件夹名称、说明文字、附魔说明、完整 NBT、拼音、标签和模糊纠错不参与首版搜索。

## 结果与存取

结果使用列表显示物品名称、数量和来源路径。长名称 / 路径截断显示，悬停查看完整内容。
同一种物品分散到不同目录时分别列出；附加数据不同的物品仍是独立条目。
最小窗口每页显示的列表条数少于普通目录的卡片数。

- 单击选择；右键取 1 个；Shift 点击取最多 64 个。
- 数量框、“全部”和“取出”沿用普通目录的规则，背包装不下的部分保留在存储中。
- 点击“定位”或双击结果，退出搜索并打开真实来源目录，自动翻页并高亮条目。
- 搜索中禁用存入、移动和目录修改；Shift 点击背包与携带物品点击结果区也不会隐式存入。
  普通背包整理仍可用，先定位 / 退出后再存入或移动。
- 取出后保留搜索并刷新结果；物品已被取空、移动或硬盘离线时，旧结果操作会被拒绝。

## 同步与兼容边界

服务端分块发送当前盘的条目 ID、目录 ID、注册 ID 和未展开的名称组件。
客户端按当前语言匹配，服务端重新检查范围，并只发送当前结果页的完整物品样本与数量。
数量变化不触发名称目录重发；条目增删、换目录和目录结构变化更新搜索目录。

搜索取出与定位检查盘挂载会话、库存版本、搜索版本以及实际发布的结果页来源。
客户端匹配集合不能替代这些校验，失败请求不会自动重放取出。
拔盘、重装、换机箱、切盘、离开终端或关闭菜单后，旧请求失效。

标准翻译组件保留名称键及参数，可按客户端语言解析普通名称和药水等变种。
若其他模组在服务端提前将名称转换为某一种语言的普通文本，无法仅凭组件恢复其他语言，
此类物品仍可按传来的名称及注册 ID 搜索。

本版模组版本为 `0.4.0-dev`，网络协议为 `6`，双方需安装同一版。
终端与硬盘的持久化格式不变；未新增第三方模组依赖。
