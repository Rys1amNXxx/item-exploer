# Item Explorer 0.5.0 · 便携终端、区块维持与设备音效

新增可随身使用的便携终端与基站区块维持模块，并为设备操作加入音效、粒子反馈和更轻巧的手持模型。

## 更新内容

- **便携终端**：在固定终端开放便携访问后，潜行右键实地配对；通过开启无线联网的完整基站，在同一维度随身浏览本地盘与 NAS、搜索、存取物品及手动合成。每台便携终端独立保存默认盘和浏览位置，固定终端可关闭访问或撤销全部配对。
- **基站区块维持模块**：替换一个空白模块并在控制器开启后，维持以控制器所在区块为中心的 3 × 3 区块，支持重启恢复和世界边界预览。默认全服最多 16 座，可由服务器配置调整；旧设备升级后默认关闭。
- **六种设备音效**：硬盘安装、硬盘弹出、终端发送成功、菜单操作失败、基站成型、自动程序整批完成。支持中英文字幕、原版音量控制和资源包替换；重复提示限频，后台刷新、读档和取消程序不重复播放完成音。
- **设备粒子反馈**：新增 NAS 与物流接口故障提示、基站成型效果及区块维持模块运行脉冲。
- **便携终端外观**：缩薄机身、缩短天线，调整第一人称双手和第三人称持握的比例、位置与朝向，减少手持时的遮挡。
- **批量存入修复**：背包中的 Shift + 双击按原版习惯一次存入所有同类物品，服务端用一次请求处理。

便携终端不支持跨维度访问，也不会自动加载基地；目标终端、NAS、基站和完整导线路径需保持加载。区块维持范围固定为 48 × 48 格、覆盖整个世界高度，范围外的设备仍可能卸载。便携访问沿用现有固定设备交互规则，尚无玩家所有权或分级权限系统。

## 安装与升级

需要 Minecraft **1.20.1**、Forge **47.0.0 至 48.0.0 之前的 47.x**、**64 位 Java 17**。

下载附件 `itemexplorer-1.20.1-0.5.0.jar`，替换 `mods/` 中的旧版 Item Explorer。
附件 `SHA256SUMS.txt` 提供下载校验值；GitHub 自动生成的 Source code 压缩包不是可安装模组。

**网络协议由 0.4.4 的 14 更新为 17，客户端和服务端必须同步升级到 0.5.0。** 不能与 0.4.4 或更早版本、协议 15 / 16 的开发构建混用。
继续读取已有终端、目录、默认盘与 NAS 硬盘数据；便携授权和区块维持设置作为新增字段保存。升级前备份存档并退出游戏或停止服务器。
