# Item Explorer 0.4.2 · 当前目录中键排序

在终端右侧物品区按鼠标中键，即可排序当前目录的全部物品，包含其他页的条目；排序后返回第一页。

## 排序规则

- 按物品注册 ID（`模组名:物品名`）的字典序升序排列，同种物品集中显示。
- 同 ID 的不同附魔、耐久或自定义名称条目保持固定先后，不合并或修改物品数据。
- 只作用于当前目录的物品；文件夹、程序文件、子目录内容和玩家背包不参与排序。
- 支持终端本地盘和 NAS 硬盘，排序结果随正常存档保存，重新打开后保留。
- 按一次中键排一次；之后新存入的物品种类追加到末尾，可再次按中键排序。
- 鼠标未拿物品时可触发；搜索期间先退出搜索或定位到来源目录，再排序。

## 安装与升级

需要 Minecraft **1.20.1**、Forge **47.0.0 至 48.0.0 之前的 47.x**、**64 位 Java 17**。

下载附件 `itemexplorer-1.20.1-0.4.2.jar`，替换 `mods/` 中的旧版 Item Explorer。
附件 `SHA256SUMS.txt` 提供下载校验值；GitHub 自动生成的 Source code 压缩包不是可安装模组。

**网络协议由 12 更新为 13，客户端和服务端必须同步升级到 0.4.2。**
存档格式不变，继续读取已有终端和 NAS 硬盘数据。升级前备份存档并退出游戏或停止服务器。
