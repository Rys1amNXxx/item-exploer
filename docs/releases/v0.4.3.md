# Item Explorer 0.4.3 · 物品合并与空格操作修复

修复同类物品因空 NBT 标签分成多个条目，以及 Shift 点击空背包格时误报存入失败的问题。

## 修复内容

- Shift 点击空背包格不再发出存入请求，也不再显示“存储已满，或没有可存入的物品”。
- 物品合并遵循 Forge 堆叠规则，无 NBT 标签与空标签 `tag: {}` 的同类物品可以合并；真实的名称、附魔、耐久等 NBT 差异及模组能力数据（Forge capabilities）仍按兼容性分别保留。
- 中键整理会先合并当前目录中可堆叠的旧条目，再按物品注册 ID 排序；终端本地盘与 NAS 硬盘均适用，物品总数保持不变。
- 存入、移动、取出使用一致的堆叠判断，原有自动加工程序保存的物品样本继续兼容。

## 安装与升级

需要 Minecraft **1.20.1**、Forge **47.0.0 至 48.0.0 之前的 47.x**、**64 位 Java 17**。

下载附件 `itemexplorer-1.20.1-0.4.3.jar`，替换 `mods/` 中的旧版 Item Explorer。
附件 `SHA256SUMS.txt` 提供下载校验值；GitHub 自动生成的 Source code 压缩包不是可安装模组。

**网络协议仍为 13，存档格式不变；多人游戏请将客户端与服务端同步更新到 0.4.3。**
继续读取已有终端和 NAS 硬盘数据。升级前备份存档并退出游戏或停止服务器。

已有的分裂条目不会在升级时自动整理。打开它们所在的原目录，鼠标未拿物品时在右侧物品区按中键，即可合并并排序；不同目录需分别整理。

## 验证

- **200 项 GameTest** 通过，覆盖空背包格操作、无标签与空标签物品合并、真实附加数据与数量保留、本地盘与 NAS 整理、存入 / 移动 / 取出，以及原有自动加工样本兼容。
- 发布构建检查版本元数据与 SHA-256，发布 JAR 不包含 GameTest 代码。
