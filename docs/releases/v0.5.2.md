# Item Explorer 0.5.2 · JEI 配方填充与界面修复

固定终端和便携终端新增可选 JEI 配方填充，并修复自动程序选择弹窗的文字重叠。

## 更新内容

- **JEI 配方填充**：打开工作台配方后点击「＋」，从背包、快捷栏和现有合成格填入一组材料；Shift + 点击按完整配方尽量填满。填充后仍需玩家领取合成结果。
- **退料与设备保护**：缺料或无法归还旧合成格材料时阻止填充，并显示原因；不会使用正在操作的便携终端所在槽位。旧合成格空间预检按物品及附加数据计算，不修改实际库存。
- **生产弹窗修复**：选择目录、物品或机器时停止绘制底层配方文字和图标，解决穿透弹窗、文字叠在一起的问题。
- **模型调整**：调整区块维持模块主体和前面板的几何结构。

JEI 为可选依赖，不随安装包捆绑；未安装时原有手动合成照常可用。此版本不支持通过 JEI 从终端或 NAS 存储自动取料，也不生成自动程序或自动领取产物。

## 安装与升级

需要 Minecraft **1.20.1**、Forge **47.0.0 至 48.0.0 之前的 47.x**、**64 位 Java 17**。

下载附件 `itemexplorer-1.20.1-0.5.2.jar`，替换 `mods/` 中的旧版 Item Explorer。
附件 `SHA256SUMS.txt` 提供下载校验值；GitHub 自动生成的 Source code 压缩包不是可安装模组。

**使用 JEI「＋」填充时，客户端和多人服务器都需要安装对应 Minecraft 1.20.1 Forge 的 JEI。** 本次实测 JEI **15.20.0.106**。

网络协议保持 **21**，存档格式不变，继续读取 0.5.1 的库存、磁盘、程序和设备配置。建议客户端与服务器统一升级到 0.5.2；不能与 0.5.0 或更早发布版混用。升级前备份存档并退出游戏或停止服务器。
