# Item Explorer 0.4.4 · 默认盘与界面材质包适配

新增终端默认盘设置，让界面复用原版 GUI 资源，并修复硬盘容量标签的展示朝向。

## 更新内容

- **终端默认盘**：切换到常用盘后点击“设为默认盘”，再次打开该终端会进入指定盘根目录。设置按终端保存，重启后保留，所有使用者共用；硬盘改名、换槽位或迁移到仍可连接的 NAS 不影响设置。默认盘离线或处于数据保护状态时暂用本地盘，重新接回后恢复。
- **通用界面材质包适配**：终端、NAS、物流接口、机器接口、基站及远程传输界面复用原版按钮与工作台 GUI 资源。背包、快捷栏和合成区保留完整槽位装饰，自定义大面板从贴图提取背景和边框主色，不再拉伸或重复平铺局部装饰。
- **高清、透明度与重载**：支持沿用原版布局的高清 GUI 贴图，保留透明度并按背景调整文字对比度；切换资源包或按 F3+T 后刷新，无需重启游戏。
- **硬盘显示修复**：调整四种容量硬盘的背包与第一人称模型朝向，让容量标签面朝向玩家；同步更新资源生成脚本，避免重新生成后恢复错误朝向。

材质包需替换 Minecraft 1.20.1 对应原版 GUI 资源并保持原版 UV 布局。只修改方块或物品的材质包不会改变界面；自定义大面板继承配色，不复刻整幅插画。重新排列控件或依赖其他模组的自定义 GUI 不保证完整兼容，不针对单一材质包做特殊适配。

## 安装与升级

需要 Minecraft **1.20.1**、Forge **47.0.0 至 48.0.0 之前的 47.x**、**64 位 Java 17**。

下载附件 `itemexplorer-1.20.1-0.4.4.jar`，替换 `mods/` 中的旧版 Item Explorer。
附件 `SHA256SUMS.txt` 提供下载校验值；GitHub 自动生成的 Source code 压缩包不是可安装模组。

**网络协议由 13 更新为 14，客户端和服务端必须同步升级到 0.4.4，不能与旧版混用。**
继续读取已有终端和 NAS 硬盘数据，默认盘设置作为可选字段保存；升级前备份存档并退出游戏或停止服务器。

本次仅发布 Item Explorer，不包含其他模组的独立兼容补丁。
