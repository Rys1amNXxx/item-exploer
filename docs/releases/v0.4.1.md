# Item Explorer 0.4.1 · Forge 兼容性修订

降低 Forge 最低版本要求，让 Minecraft 1.20.1 的较旧 Forge 整合包也能加载本模组。

## 修改

- 将 Forge 最低版本从 47.4.23 降至 **47.0.0**，涵盖使用 47.3.22 的 Minecraft 1.20.1 整合包。
- 使用旧版支持的 Mod 无参构造入口和资源路径构造方法；开发构建也固定为最低 Forge 版本，避免再次无意中依赖较新 API。
- CI 以 47.0.0 编译，并在 47.0.0、47.3.22、47.4.23 上运行已有 GameTest。
- 兼容测试与重启测试辅助代码同步改用旧版资源路径接口。

## 安装

Minecraft **1.20.1**、Forge **47.0.0 至 48.0.0 之前的 47.x**、**64 位 Java 17**。
下载发布附件 `itemexplorer-1.20.1-0.4.1.jar`，替换 `mods/` 中的旧版 Item Explorer；客户端和服务端均使用同一构建。
附件 `SHA256SUMS.txt` 提供下载校验值；GitHub 自动生成的 Source code 压缩包不是可安装模组。
本次只调整加载器兼容性，玩法、存档格式和网络协议（12）不变。
旧 GitHub v0.4.0 附件仍要求 Forge 47.4.23，降低限制需要使用本次新构建。

## 验证

Forge **47.0.0、47.3.22、47.4.23** 均通过各 **187 项 GameTest** 和真实中文客户端检查，包括基站、NAS、导线连接、物品取出和界面渲染。
三组测试使用在 47.0.0 上编译的同一份生产代码。完整用户整合包未实测。

验证结果和复跑方式见 [Forge 兼容性验证](https://github.com/Rys1amNXxx/item-exploer/blob/v0.4.1/docs/verification/2026-10-15/forge-compatibility.md)。
