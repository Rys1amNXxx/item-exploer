# Item Explorer 0.5.1 · 通用机器加工与终端界面更新

新增多端点通用物品加工、终端紧凑网格视图与设备状态显示，并重做物流接口和自动程序配置界面。

## 更新内容

- **通用机器加工**：通过 Forge 物品接口接入第三方机器，每批最多 9 种输入和 9 种产物。每行可独立指定目录、设备端点、机器面和槽位，支持普通投入、保留工具、按量补给、必需产物与可选产物。参与接口独占运行，断线暂停，未投料和已收取产物保留缓冲并按规则归还。
- **自动程序配方总览**：加工配方、连接设置、运行三页配置；左右物品格同时显示原料和产物，支持搜索样本、目录与机器，预览批次总量，以及保存后试做 1 批。保存失败或配置发生变化时不会自动投料。
- **终端紧凑网格**：在文字卡片与物品图标网格之间切换，并记住本机显示偏好。
- **物流接口界面**：左侧选择磁盘，右侧展开目录树；显示当前绑定、待应用选择、输入／输出与子目录开关，选择完成后统一应用。
- **设备状态反馈**：机器接口以暗灯、青色脉冲、琥珀、红色和短暂绿灯表示待机、加工、等待、异常与完成；基站新增独立无线联网灯。终端屏幕自发光，并随待机、打开和数据保护状态切换画面。
- **界面与加工修复**：统一机器界面的文字色调、长文本省略与操作提示；修复通用加工槽位分配及切换原料目录时的样本选择。

通用加工只搬运物品，机器配方、供电和工作模式仍由玩家配置；不包含流体、气体或自动配方规划。机器应专用于对应程序，避免其他管道或玩家操作相同槽位。原版熔炉、高炉、烟熏炉和酿造台程序继续保留。

## 安装与升级

需要 Minecraft **1.20.1**、Forge **47.0.0 至 48.0.0 之前的 47.x**、**64 位 Java 17**。

下载附件 `itemexplorer-1.20.1-0.5.1.jar`，替换 `mods/` 中的旧版 Item Explorer。
附件 `SHA256SUMS.txt` 提供下载校验值；GitHub 自动生成的 Source code 压缩包不是可安装模组。

**网络协议由 0.5.0 的 17 更新为 21，客户端和服务端必须同步升级到 0.5.1。** 不能与 0.5.0 或更早发布版、协议 20 及更早的开发构建混用。
继续读取已有终端、目录、NAS 硬盘、便携授权、区块维持设置和原版自动程序。升级前备份存档并退出游戏或停止服务器。

## 验证

- 使用 Java 17、Forge 47.0.0 构建正式 JAR，并将同一份最低版本编译的代码分别运行于 Forge **47.0.0、47.3.22、47.4.23**；每个版本均通过 **304 项必需 GameTest**。
- 物流接口、基站与数据导线的模型／资源检查通过，基站检查同步覆盖新增联网灯及四个朝向的组合几何。
- 实际客户端通过 **10 组资源场景、90 次截图与像素断言**，覆盖终端最小／最大布局、机器界面、1×／2×／4× 资源、透明度和移除资源包后的恢复；同步修正回归脚本的配方格取样位置及窗口缩放等待。
- 发布 JAR 已核对版本元数据、关键资源和 SHA-256，未包含 GameTest、客户端探针或第三方模组类。

本次发布验证在本地完成，未取得 GitHub Actions 的成功运行结果。
