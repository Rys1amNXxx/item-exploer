# Item Explorer 0.4.0 · 物品资源管理器

首个 GitHub 发布版，提供 Minecraft Forge 的物品存储、目录管理与终端间传输。

## 主要功能

- 存储终端与目录树：按目录分类物品，支持指定数量存取、移动、搜索和定位。
- NAS 与硬盘：四盘位 NAS、64K 至 16M 硬盘，通过数据导线接入多个机箱。
- 手动工作台与自动加工：终端内 3×3 工作台、目录程序文件、物流接口及原版机器加工。
- 基站与终端传输：同基站终端可直接传输；不同基站须双方开启无线联网，并处于同一维度。
- 紧凑发送界面：直接选择接收终端、查看收件目录、使用 `1 / 16 / 64 / 最大` 快捷数量，核对发送摘要与剩余库存；本机收件设置独立打开。

## 运行要求与安装

- Minecraft **1.20.1**。
- Forge **47.4.23 或更新的 47.x**（发布构建使用 47.4.23）。
- **64 位 Java 17**。

下载发布附件 `itemexplorer-1.20.1-0.4.0.jar`，放入游戏实例或服务器的 `mods/` 目录。
多人游戏的客户端与服务端必须使用相同构建。GitHub 自动生成的 Source code 压缩包不是可安装模组。

升级前备份存档，退出游戏或停止服务器，移除旧版 Item Explorer JAR 后再放入新文件。
继续读取既有终端版本 1 存档与硬盘数据；网络协议为 **12**。
附件 `SHA256SUMS.txt` 提供下载校验值。

## 传输规则与边界

- 单次发送 **1–64 件**物品；成功后每座参与基站冷却 **20 tick**。源库存不足或目标容量不足时整单拒绝。
- 仅向已加载、可达且主动开启接收的终端发送，不主动加载区块，不支持跨维度，也不开放远端库存浏览。
- 接收终端失效或收件配置变化时清空旧选择，不自动改投其他终端或目录。
- 尚无玩家权限、白名单或私有频道；可操作设备的玩家能够修改配置。
- 沿用现有世界与硬盘保存机制，不保证进程强杀、断电或保存中断时的跨文件原子恢复。

- 正式版本构建及 **187 项 GameTest** 通过。
