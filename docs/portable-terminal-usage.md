# 便携终端（0.5.0 开发版）

便携终端让玩家在同一维度内随身访问一台固定终端的本地盘与可达 NAS 硬盘。
库存继续保存在基地设备中；掌机只保存配对信息、默认盘和浏览位置。无需充电，也不消耗能量。

## 合成与配对

配方使用 4 个铁锭、1 个末影珍珠、1 个金锭、1 个红石粉、1 个红石比较器。

```text
空   末影珍珠  金锭
铁锭  红石粉   铁锭
铁锭  比较器   铁锭
```

获得固定终端后解锁配方。创造模式可在模组分页找到，或使用 `/give @s itemexplorer:portable_terminal`。

1. 打开家里的固定终端，在未选中物品时点击顶部“终端设置”，再点击“便携访问”。已选中物品时，进入“发送”后点击“终端设置”即可。
2. 开启“便携访问”。该开关独立于“允许接收物品”，原有终端升级后默认关闭便携访问。
3. 手持便携终端，潜行右键固定终端进行配对。主手、副手均可；一台便携终端只绑定一个目标，重新配对会替换旧目标。
4. 将固定终端通过数据导线连接到结构完整的基站，并在基站控制器开启无线联网。配对可以提前进行，但无线访问需要基站就绪。
5. 在同一维度内，手持便携终端对空右键打开存储界面，距离不限。

可在终端设置中给固定终端命名。便携界面标题显示目标名称，左上角掌机图标可悬停查看完整名称和连接状态。

## 日常使用

便携窗口沿用原有目录树、搜索、指定数量存取、目录改名与删除、中键整理、NAS 切盘和 3×3 手动合成。
搜索和合成规则与固定终端相同。远程发送、收件设置及自动程序管理仍在固定终端使用。

点击“设为默认盘”只修改当前便携终端的偏好，不影响固定终端或其他便携设备。
再次打开时使用该默认盘；仅当上次浏览盘与默认盘一致时，恢复有效的上次目录与分页。每台设备只记住一处上次浏览位置，不分别记录每块盘的位置。默认盘暂时不可用时使用本地盘，保留原偏好。
使用期间当前盘断线会停止存取，不会把物品自动存到其他盘。

正在使用的便携终端槽位会锁定，防止把当前访问凭据存进正在访问的仓库。关闭窗口后即可移动设备。
关闭窗口时，合成材料按原版规则返还背包，放不下的部分掉落在玩家身边。
物品本身可以交给其他玩家；持有已配对设备的玩家能够访问对应库存。

## 断线与区块加载

便携终端本身不会强制加载区块。固定终端、使用的 NAS、基站结构和导线路径都需要保持加载。
可把基站底座中的一个空白模块换成**区块维持模块**，在控制器“区块维持”页开启，确认状态为“正在维持 9 个区块”。
这会持续加载以控制器所在区块为中心的 3 × 3 区块，覆盖 48 × 48 格和整个世界高度。一个模块即可，多个不叠加范围，无需供电。
把终端、NAS 和整段导线放在窗口显示的范围内；点击“显示世界边界 60 秒”后关闭窗口，可实地查看边界。
范围外的设备仍可能卸载。关闭开关、拆掉模块或破坏基站会释放对应加载；加载上限默认全服 16 座基站，由服务器配置控制。
区块维持与无线联网相互独立，便携访问仍需要基站开启无线联网。本版不支持跨维度访问，也不会在打开掌机时自动唤醒未加载的基地。
模块配方、范围和服务器配置见 [基站使用说明](base-station-usage.md#区块维持模块050-开发版)。

| 提示 | 处理方式 |
| --- | --- |
| 尚未配对 | 在固定终端开启便携访问，然后潜行右键配对 |
| 配对终端所在区块未加载 | 返回基地开启区块维持，并确认终端位于覆盖范围内 |
| 基站或连接路径未加载 | 检查区块维持状态，并把基站结构及整段导线放在覆盖范围内 |
| 基站不可用 | 检查基站结构、控制器和数据导线 |
| 基站无线联网已关闭 | 在基站控制器开启无线联网 |
| 配对终端已关闭便携访问 | 到固定终端重新开启便携访问 |
| 配对已撤销或数据无效 | 回到目标终端重新配对；原地放置新终端不会继承旧授权 |
| 配对终端位于其他维度 | 返回配对时的维度 |
| 磁盘离线 | 检查对应 NAS、盘位和导线，或切换到另一块在线盘 |

已打开窗口在连接中断时保留浏览上下文并显示具体原因，暂停存取。设备恢复可用后，窗口重新同步库存。
设备被移出原槽位、切换维度或进入旁观模式时，会结束访问；再次使用设备时重新验证连接。

## 撤销与管理

在固定终端的“终端设置 → 便携访问”中可查看已登记设备数，每台固定终端最多登记 64 台。

- 关闭访问：临时断开所有便携终端，重新开启后原配对继续有效。
- 撤销全部配对：5 秒内连续点击两次确认，所有便携设备都必须回到固定终端重新配对。

这些设置和授权随存档保存，不依赖收件目录或收件开关。便携终端丢失不会搬走仓库中的物品，撤销配对可使遗失设备的访问凭据失效。
本版沿用固定设备的交互规则，可接近固定终端的玩家可以管理它；尚未加入玩家所有权或分级权限系统。

## 版本兼容

该功能属于 `0.5.0-dev`，不是已发布的 `0.4.4` JAR 内容。当前开发版网络协议为 17，客户端与服务器必须使用相同协议版本。
终端授权作为可选字段保存；旧世界中的库存、目录和默认盘保持兼容。
