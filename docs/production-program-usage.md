# 终端目录中的自动程序

更新日期：2026-10-01。

自动程序是保存在终端本地文件夹中的文件。像打开桌面系统中的程序一样，点击文件即可进入其配置和运行窗口。
程序保存机器与材料目录等规则，每次启动单独指定执行次数；机器接口负责连接和执行。
本阶段支持原版熔炉、高炉、烟熏炉、酿造台，工作台自动化留待后续独立的计时自动合成台。

## 搭建与创建

1. 放置支持的专用机器，清空全部物品槽。酿造台还需等待原有酿造结束。
2. 拿着“机器接口”，潜行右键机器表面安装。六面均可安装，每台机器只安装一个接口。
3. 从接口朝外的连接杆接数据导线，连到一个存储终端的任意面。无需基站或额外供电。
4. 在终端**本地盘**准备原料、燃料或辅料、成品目录，并存入要选择的物品样本；这些目录可以相同。
5. 进入想保存程序的文件夹，点击“新建”，将类型切换为“自动程序”，输入名称后确认。
6. 左键打开程序文件，点击机器行选择已连线设备，选择来源目录、物品样本和产物目录。各选择行支持点击切换、Shift 点击反向切换。
7. 点击“保存”，确认显示的产物，填写本次执行次数，再点击“启动”。返回文件夹或关闭窗口后，已加载的机器继续执行。

程序的创建、配置和启动都在终端完成，运行状态也在终端程序窗口中查看。
程序修改后需先保存再启动；右上角返回按钮或 Esc 回到来源文件夹，未保存的编辑会丢失。

接口可在创造分页获取，或使用 `/give @s itemexplorer:production_port`。
物品注册 ID 保持不变；合成材料为 2 个铁锭、2 个红石粉、1 个红石比较器：

```text
空   铁   空
红石 比较器 红石
空   铁   空
```

## 文件操作

| 操作 | 方法与结果 |
| --- | --- |
| 打开 | 左键点击程序文件；也可右键选中后点击“打开” |
| 改名 | 右键选中文件，点击“改名” |
| 移动 | 右键选中文件，点击“移动到…”并选择本地盘目标文件夹 |
| 复制 | 右键选中文件，点击“复制”；同目录自动生成唯一名称，如 `程序 (2).exe`，副本保存规则，不复制原料、成品或运行任务，也不会自动启动 |
| 删除 | 右键选中文件，点击“删除”；运行中的程序须先取消 |

每个终端最多 **32 个程序文件**，文件名最长 24 个 UTF-16 代码单元。同一文件夹不能有重名程序。
程序不占物品容量或物品条目数，不可取入背包；包含程序的文件夹不能直接删除。
运行中的程序不能修改、改名、移动或删除；可以复制其已保存定义。
移动程序文件或重命名目录不改变材料绑定，绑定使用稳定目录身份而不是显示路径。
本版在 NAS 硬盘及物品搜索视图中不提供程序文件操作，物品搜索不会列出程序。

## 次数、目录与机器规则

每次启动填写 **1–4,096 次**。保存程序不消耗物品，运行次数也不会改写保存的定义。
例如沙子、煤炭、32 次表示在所选熔炉完成 32 次沙子烧玻璃；燃料消耗按实际燃烧计算，不等于加工次数。

- 仅使用同一终端本地盘明确选择的目录，不包含子目录，不借用其他目录的库存。
- 物品及附加数据精确匹配；补货产生新条目编号后仍可继续。药水类型、名称、耐久等不同不会被当作相同样本。
- 每次只投入一个原料，真实成品交付到指定目录后才累计完成次数。
- 目录被删除后暂停，不改投根目录。终端、机器或接口被同位置的新设备替换后需重新绑定。
- 一台机器一次执行一个任务；多个文件可以保存相同机器，但不能同时占用它。同一终端可连接多台机器并分别运行。
- 生产线路必须恰好连接一个终端，沿用 256 段导线上限。只处理已加载区块，不主动强制加载设备或导线。

| 机器 | 加工与耗材 |
| --- | --- |
| 熔炉 | 使用原版熔炼配方、加工时间和燃料，优先利用余火 |
| 高炉 | 仅使用高炉支持的配方，保留原版高炉速度与燃料规则 |
| 烟熏炉 | 仅使用烟熏炉支持的配方，保留原版烟熏炉速度与燃料规则 |
| 酿造台 | 每次处理一瓶基础药水及一份酿造材料，按原版酿造时间加工；自动从辅料目录补充普通烈焰粉 |

三种炉子的燃料容器返还到燃料目录。熔岩桶返还空桶；湿海绵烧制保留原版空桶变水桶行为。
烧制经验留在原版机器内。启动前需清空物品槽，已有燃烧余量可以继续使用。

酿造程序的“基础药水目录”提供瓶装原料，“辅料目录”同时提供所选酿造材料和**未命名、无附加数据的普通烈焰粉**。
烈焰粉补充酿造台的原版燃料储量，可供多次酿造使用；如果配方本身也使用烈焰粉，配方消耗和燃料补充分别计算。
程序只使用第一个瓶槽（槽位 0），另外两个瓶槽必须为空；这是单瓶程序，不按三瓶一批执行。
龙息返还的玻璃瓶进入辅料目录。完整加工后保留酿造台剩余燃料，供下次运行使用。

**运行时使用专用机器，避免玩家、漏斗和其他管道同时存取。**
检测到非预期库存变化会停止自动操作，并保持异常状态直到取消。
本版没有锁住机器的外部访问，无法识别所有同种物品的外部替换。

## 等待、取消与拆除

| 情况 | 行为 |
| --- | --- |
| 缺原料、燃料、酿造材料或烈焰粉 | 显示等待原因；补入对应目录后自动继续 |
| 容量或条目上限不足 | 暂停投料，真实产物和待返还容器留在机器中 |
| 导线断开或必要区块未加载 | 停止送料和回收；已加载的机器仍可能完成已投入的加工，恢复连接后重新核对 |
| 目录失效或数据保护 | 停止转移，保留真实库存 |
| 同位置替换终端、机器或接口 | 稳定身份不匹配，不能接管新设备；取消后重新保存绑定 |
| 检测到外部干预 | 保持异常状态，恢复物品原样也不自动继续；检查后取消 |
| 点击“取消运行” | 停止控制，不移动机器中的物品，不生成退款；原版机器可能继续加工 |
| 拆除接口 | 终端里的程序文件保留，机器绑定失效；机器内物品仍留在机器中 |
| 拆除机器 | 接口随依附关系移除，机器库存按原版规则处理；终端程序文件保留 |
| 拆除终端 | 本地库存按终端规则掉落，程序文件和目录不随掉落的终端方块保存 |

取消后重新运行前，先取出机器残留物，酿造台需等待正在进行的原版酿造结束。
已交付成品始终留在产物目录中。断线时仍可从终端程序窗口取消；重新连回的旧任务不能继续使用已取消的运行身份。

## 从接口原型升级

早期原型把配置和任务保存在接口里。本版读取这些旧数据时停止旧任务的自动控制。
已投入机器的原料、燃料、成品和原版加工进度全部留在机器中，机器仍可能自然完成加工。
取出残留物后，在终端文件夹中新建程序并配置。旧接口配置不会自动变成目录文件，也不会在后台隐形继续运行。

## 存档与实现范围

程序库保存在终端中，和物品库存分开；接口保存本次运行的定义快照、执行次数、进度和适配器状态。
终端、机器、接口及每次运行都有持久化身份。保存定义不会改写正在执行的快照，复制文件不会继承运行占用。
未知版本或损坏的数据进入保护状态，保留原始数据，并尝试归档到世界的 `itemexplorer-recovery/`。
菜单请求校验打开会话、修订、玩家与终端的距离、设备身份和连通性。

终端、接口和机器仍分别保存，尚未提供保存中断或进程崩溃时的跨设备原子恢复保证。
本版不支持 NAS 生产、跨盘取料、子目录递归、排队、多步骤流程、自动配方规划或第三方机器。
手动工作台和独立自动合成台尚未实现；后续自动合成采用专用计时设备，不在终端即时完成自动合成。
总体设计及历史讨论见 [生产程序设计](production-program-plan.md)。


覆盖实际加工、目录文件操作、耗材与容器、断线与取消、正常序列化、异常数据和旧运行身份。
测试源码与独立服务端重启或真实多人网络验收的范围不同；实际结果以本次验证报告为准。
本次构建、148 项 GameTest 和真实中文客户端流程已通过，记录及截图见 [验证报告](verification/2026-10-01/terminal-programs/README.md)。
