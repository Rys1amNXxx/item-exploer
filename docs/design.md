# 首版范围

## 产品目标

玩家合成、放置一个独立存储设备，通过资源管理器式窗口存取物品、创建文件夹、移动分类。
不依赖 AE2，不要求前置科技流程。当前只完成项目环境搭建。

## 已讨论的设计方向

- 同种且完整数据一致的物品按条目聚合，并单独记录数量。
- 普通文件夹分配实际库存；同种材料可以按数量分配到不同目录。
- 所有文件夹共享设备容量。
- 整理目录和取出到背包是不同操作。
- 删除文件夹不能销毁物品；首版可只允许删除空目录。
- 服务端负责存取和数量校验，界面只发送操作请求。

容量、合成配方、设备拆除后的库存保留方式尚待确定。

## 实现顺序

1. 注册存储方块与方块实体，完成存取及存档往返。
2. 实现目录树和物品条目模型，支持建立、改名、按数量移动。
3. 实现菜单与客户端界面，接入目录树、物品区和玩家背包。
4. 加入拖拽和键盘交互，并适配 GUI 缩放。
5. 验证背包满、快速操作、多人操作、区块卸载、方块拆除。

库存逻辑尽量与界面解耦。未来迁移游戏版本时，集中处理物品序列化、网络和界面接口变化。
