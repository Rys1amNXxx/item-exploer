Bottom plan from rear to front: casing / network port / casing; blank module / casing / blank module; casing / controller / casing. At y=3, a third matching central mast section has FOUR short square horizontal radial arms pointing north/south/east/west, connecting seamlessly to FOUR separate slim upright rectangular antenna panels in the four adjacent grid cells. All four panels are at the SAME height, each only one block tall, with their flat fronts facing OUTWARD and their backs connected to the central mast by short arms. Each panel is 10/16 block wide, 14/16 block tall, 2/16 block thick. Their surfaces are ivory-gray with crisp pixel dark grooves and a restrained tiny cyan indicator. No dish, no diagonal bars, no long pipe protrusions. Entire antenna assembly stays inside the same 3x3 footprint. Four panels even if rear one is partially occluded. Central mast crosshead is one grid position plus the four panel positions.
At y=4, ONE narrow antenna cap block centered above mast, tapered only via axis-aligned stepped cuboids: small light-gray collar then a narrow dark vertical finial with tiny cyan tip. Entire cap fits one grid cell. Overall height exactly FIVE blocks from ground through cap. Overall material count seventeen placed blocks (9 bottom + 2 mast + 5 crosshead layer + 1 cap).
